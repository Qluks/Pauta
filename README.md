# Tarefas (MVP pessoal)

1. Crie um projeto no Supabase e rode `supabase.sql` no SQL Editor.
2. Copie `.env.example` para `.env` e preencha URL e chave anon (Project Settings > API).
3. `npm install` e depois `npm run dev`.

Dica: em Authentication > Providers > Email, desative "Confirm email" durante o desenvolvimento.
